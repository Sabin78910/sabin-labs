# Sabin Labs

**Built in the Himalaya. Made for the world.** The company hub for every Sabin Labs product.

**Live:** https://sabin78910.github.io/sabin-labs/

![CI](https://github.com/Sabin78910/sabin-labs/actions/workflows/ci.yml/badge.svg)

- **Product suite:** all 15 products by category, each with live status, what makes it better than the category leader, and links.
- **Sabin Labs ID:** one end-to-end encrypted code shared by every web app on this origin (no password, no email). It shows which apps are synced and can erase everything in one step. Powered by [sync-api](https://github.com/Sabin78910/sync-api).
- **Platform:** how the company ships around the clock: research, the cloud AI engineer, CI gates, deploys and monitoring.
- **Company:** principles (fair, private, respectful delight, Nepal first) and focus bets.
- **Status:** live checks of every web app and API from the visitor's browser.

```bash
npm ci && npm run dev
npm test
```
